Statistical Methodology

How the analysis engine works

Full documentation of test selection, effect sizes, multiple comparison corrections, and replication criteria. Built on Welch's framework with G*Power-validated power analysis.

1. Study design (V0)

V0 supports between-subjects designs only: each AI persona responds to one condition. Personas are not reused across conditions, eliminating carryover and order effects that complicate within-subjects LLM experiments.

Within-subjects designs are not available in V0. The API rejects studies with design_type != "between_subjects" with an explicit error message.

2. Automatic test selection

The analysis engine inspects each question's scale_type, scale_points, and the number of experimental conditions, then routes to the appropriate test. No manual test selection is required.

Why Welch's t — not Student's t

LLM temperature and demographic sampling create unequal within-group variance across conditions. Student's t assumes homoscedasticity (equal variances); when violated, it inflates Type I error and produces overconfident confidence intervals. Welch's t-test uses the Welch–Satterthwaite degrees-of-freedom adjustment and is the unconditional default, following Delacre, Lakens & Leys (2017).

Delacre, M., Lakens, D., & Leys, C. (2017). Why psychologists should by default use Welch's t-test instead of Student's t-test. International Review of Social Psychology, 30(1), 92–101.

Why not pre-test with Levene's

A common but problematic workflow tests for variance equality with Levene's test and switches to Welch's only if the test rejects. With the small per-condition N common in LLM studies (10–100), Levene's is severely underpowered — it routinely fails to detect unequal variance, causing incorrect use of Student's t. The platform avoids this entirely by using Welch's unconditionally.

Games-Howell post-hoc

For significant Welch's ANOVA results, pairwise comparisons use the Games-Howell procedure (does not assume equal variances or equal group sizes), implemented via pingouin.pairwise_gameshowell(). This gives per-pair p-values and effect sizes consistent with the ANOVA's heteroscedastic assumptions.

95% confidence intervals are reported for all continuous effect sizes. For ANOVA-family tests, CIs use the η² approximation from the F distribution. Overlapping CIs between AI and human benchmarks drive the Goal 2 replication criterion.

4. Multiple comparison corrections

When a study has more than one dependent variable (question), uncorrected p-values overstate evidence. The platform applies two corrections simultaneously and reports all three p-values.

  • Benjamini-Hochberg FDR (default reporting threshold) — controls the false discovery rate across all questions in the study. Less conservative than Bonferroni; recommended for exploratory replication work.
  • Bonferroni — family-wise error rate correction. More conservative; reported alongside BH-FDR for completeness.
  • Uncorrected p — always preserved so researchers can apply their own correction scheme in downstream analysis.

Results tables show all three. The replication criterion (Goal 1) uses the BH-FDR-corrected p-value by default.

5. Replication criteria

Each question is scored against two replication goals, modeled on the Viewpoints AI benchmark (Yeykelis et al., 2024/2025).

Goal 1 — Directional replication

The AI study effect is in the same direction as the human benchmark AND the BH-FDR-corrected p-value < 0.05. Both conditions must hold. A significant result in the wrong direction counts as a failure.

Goal 2 — Effect size overlap

The 95% confidence interval of the AI effect size overlaps the human benchmark effect size. This criterion checks whether the magnitude of the AI effect is plausibly consistent with the human population effect, not just directionally correct.

An overall study-level replication rate is computed as the fraction of questions meeting each goal. The Viewpoints AI (2024) benchmark achieved a 76% main-effect replication rate on Goal 1; this platform targets parity.

Yeykelis, L., et al. (2024/2025). Viewpoints AI: Replicating survey research with large language models. Preprint.

6. Sample size & power analysis

The GET /power/recommend endpoint calculates minimum N per condition. Calculations use statsmodels non-central distributions, validated against G*Power 3.1.

AI variance note: AI personas typically show lower within-group variance than human panels, so studies may reach significance at smaller N than calculated. However, narrower AI variance can also overstate effect sizes relative to human populations. We recommend not reducing N below the calculated value for a first study.

7. Known limitations (V0)

  • Between-subjects only — within-subjects and crossover designs are V1.
  • Open-ended questions excluded from statistics — text responses are collected but not analyzed in V0.
  • Temperature locked per study — calibrated once before data collection; not varied dynamically.
  • Single model — all personas use Claude Sonnet 4.x. Cross-model replication is not assessed in V0.
  • Condition names in 2-group non-parametric tests — currently display as group1/group2 rather than actual condition names (cosmetic; does not affect statistics).
